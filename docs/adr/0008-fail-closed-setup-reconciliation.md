# Fail closed on ambiguous setup commits and reconcile on restart

Single-administrator setup must never regain eligibility after an outcome may have created an administrator. Once creation can commit, interruption is masked; an ambiguous authentication or marker result disables setup, makes the process unready, and terminates it, while restart reconciliation determines durable truth. Nama sacrifices temporary setup availability rather than retrying or reopening setup locally and risking a second administrator or false eligibility.
