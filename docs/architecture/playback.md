# Playback

The tvOS client reports a Nama-defined capability profile and the Jellyfin plugin translates it into provider playback negotiation, preferring direct play, then stream-copy/remux, and transcoding only when the media/device combination requires it or the user explicitly asks; the returned provider URL and necessary short-lived authorization go directly to the client and are never logged. AetherEngine is pinned to an exact on-device-tested release behind one `NamaPlayer` wrapper with app-owned request, state, track, and error types, so Dolby Vision, HDR10/HDR10+, Atmos, subtitles, seeking, and fallback behavior can be regression-tested and the engine can later be replaced without changing UI or RPC contracts; no multi-engine factory is added before a second engine exists.
