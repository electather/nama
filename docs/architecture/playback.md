# Playback

The universal Apple app reports a Nama-defined capability profile for the current device, and the Jellyfin plugin translates it into provider playback negotiation, preferring direct play, then stream-copy/remux, and transcoding only when the media/device combination requires it or the user explicitly asks. Provider media and short-lived authorization travel directly to the client and are never logged or persisted. Playback uses one exact-pinned, security-reviewed on-device engine behind a Nama-owned adapter with app-owned request, state, clock, track, and error types; no engine type crosses that boundary and no multi-engine factory exists before a second implementation proves a shared interface. The retired AetherEngine experiment established useful rendering, seeking, audio, subtitle, HDR, and lifecycle patterns but did not approve an engine: future adoption must enforce exact-origin locator headers on redirects and every HLS subrequest, produce secret-free Release logs and errors, pass representative physical iPhone or iPad, Apple TV, and Mac media tests, and complete artifact-level distribution review.
