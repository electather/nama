# Management CLI

`nama` is a thin Go 1.26 client over generated Connect-Go services and is the complete MVP management surface: it handles initial admin setup, login and server profiles, plugin/Jellyfin configuration, sync status and triggering, device approval, health, and diagnostics without duplicating server rules. Cobra supplies command structure, complete help, and shell completions; every operation supports non-interactive flags, automation-safe `--output json`, documented stable exit codes, and credentials stored with owner-only permissions under the OS user configuration directory. The repository also ships one installable Codex `SKILL.md` that teaches agents these commands and confirmation boundaries; there is no CLI plugin framework, Viper configuration layer, interactive TUI, or web console.
